# Demo script

1. Vis repoets nye Esri-fokus og `data/` + `arcgis/` strukturen.
2. Kør eller gennemgå `create_nordic_covid_scene.py`.
3. Åbn ArcGIS Online webscenen og vis tidsregulator/3D-ekstrudering.
4. Kør eller gennemgå `create_nordic_covid_dashboard.py`.
5. Åbn ArcGIS Dashboard itemet og vis hvor den manuelle finjustering sker.
