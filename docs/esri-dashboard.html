ArcGIS Dashboard

Dashboard-overblikket bygges som et ArcGIS Dashboards workflow, hvor webkort og dashboard-item oprettes via ArcGIS API for Python.

Workflow

Kør først 3D-scenen, så det hostede feature layer findes i ArcGIS Online. Kør derefter dashboard-scriptet, som finder laget, opretter et webkort og opretter eller opdaterer et ArcGIS Dashboard. 

python arcgis/dashboards/create_nordic_covid_scene.py
python arcgis/dashboards/create_nordic_covid_dashboard.py

Output

Scriptet placerer dashboard, webkort, webscene og hosted layer i ArcGIS Online-mappen dek_2026. Åbn dashboardet i ArcGIS Online for sidste layouttilpasning og deling til konferencen.
