# Vibe coding og AI-assisteret udvikling med ArcGIS

Hvordan kan generativ AI hjælpe med at komme fra datagrundlag til publiceret ArcGIS-dashboard uden at miste kontrollen over GIS-faglighed, datakvalitet og deling?

Oplægget viser et Esri-fokuseret workflow, hvor COVID-19-data kombineres med Living Atlas-geometrier og publiceres via ArcGIS API for Python. Eksemplerne omfatter hosted feature layers, en tidsaktiveret ArcGIS 3D-webscene og et ArcGIS Dashboards setup, der kan gentages og videreudvikles.

Fokus er ikke på AI som magi, men som praktisk makker til scriptgenerering, fejlfinding, dokumentation og hurtig iteration i ArcGIS Online.

Målgruppen er deltagere ved Dansk Esri Konference 2026, der arbejder med ArcGIS og vil bruge AI mere konkret i deres egne geodata- og dashboard-workflows.
