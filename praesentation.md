# Vibe coding og AI-assisteret udvikling med ArcGIS

## Slide 1 - Velkommen og hook
- COVID-19-data + ArcGIS API for Python = webscene og dashboard på kort tid
- Fokus: Dansk Esri Konference 2026 og Esri-native workflows

## Slide 2 - Hvem er på scenen?
- Kort om Steen og arbejdet med data, geografi og AI
- Hvorfor Esri-platformen er interessant, når AI skal kobles til reelle GIS-workflows

## Slide 3 - Vibe coding vs. AI-assisteret udvikling
- AI som makker i IDE og terminal
- Samme metode, men med ArcGIS Online som målplatform

## Slide 4 - Mission briefing
- **Mål:** bygge og dokumentere et Esri-baseret dashboard workflow
- **Data:** COVID-19 KPI'er på nordisk niveau
- **Værktøjer:** ArcGIS API for Python, hosted feature layers, Web Scene, Web Map og ArcGIS Dashboards

## Slide 5 - ArcGIS 3D scene
- Propy-workflow, Living Atlas, tidsregulator og 3D-ekstrudering
- Hvad AI hjalp med: JSON-struktur, datatransformering og gentagelig publicering

## Slide 6 - ArcGIS Dashboard
- Dashboard-overblikket bygges som ArcGIS Dashboards
- Dashboardet oprettes via script og finjusteres i ArcGIS Online

## Slide 7 - Hvad er AI særligt velegnet til?
- Lyn-prototyper af ArcGIS API for Python scripts
- Review af item properties, renderer JSON og dokumentation
- Automatisering af gentagelige publiceringsflows

## Slide 8 - Overvejelser og sikkerhed
- ArcGIS-login, rettigheder og deling
- Datafølsomhed, hosting og governance
- Hvor stopper scriptet, og hvor starter manuel ArcGIS Online-konfiguration?

## Slide 9 - Takeaways
- AI er stærkest, når workflowet kan beskrives som kode
- ArcGIS API for Python giver en solid bro mellem prompt, data og portal
- Gem prompts og scripts, så demoen kan gentages og forbedres
